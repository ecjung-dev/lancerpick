# 계약서 PDF 한글 글꼴

- 파일: `NanumGothic-Regular.ttf` (원본 파일, 수정하지 않음)
- 출처: [Google Fonts / Nanum Gothic](https://github.com/google/fonts/tree/main/ofl/nanumgothic)
- 원본: https://raw.githubusercontent.com/google/fonts/main/ofl/nanumgothic/NanumGothic-Regular.ttf
- 라이선스: 동봉한 `OFL-NanumGothic.txt` (SIL Open Font License 1.1). 배포 시 함께 보존한다.
- SHA-256: `76f45ef4a6bcff344c837c95a7dcc26e017e38b5846d5ae0cdcb5b86be2e2d31`

서버의 OS 글꼴이나 외부 URL에 의존하지 않고 PDF에 사용 글리프를 포함한다. 지원하지 않는 문자(일부 이모지 등)는 조용히 지우지 않고 `[U+1F600]` 같은 코드로 표시한다. 원래 문자열은 계약 조회 응답의 `canonicalContent`에 보존된다.
